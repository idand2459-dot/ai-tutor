# Glossary

## Purpose
- Define canonical domain terms and approved short forms used across code, API routes, docs, and plans.

## Core Terms
- chat — the interactive session and message stream between the user and the AI. Not conversation, session, or dialogue.

- message — a single text input or response within a chat. Not prompt, comment, line, or post.

- tutor — the AI persona acting as a guiding instructor. Not mentor, assistant, or bot.

- quiz — an automatically generated interactive knowledge check. Not test, exam, or assessment.

- question — a single inquiry item specifically inside a quiz. Not prompt, problem, or item.

- option — a selectable choice within a quiz question. Not answer, choice, or alternative.

- proxy — the thin backend routing requests to the Anthropic API. Not gateway or middleware.

- system prompt — the baseline instruction set governing the AI tutor behavior. Not persona or instructions.

-correct-option — the designated right choice among options in a quiz question. Not correct-answer.
## Naming Alignment
- Keep this glossary aligned with naming decisions in `../.claude/rules/naming.md`.
- If a new domain term is introduced, add it here before broad usage.
- Avoid synonyms for existing terms unless explicitly approved and documented here.
